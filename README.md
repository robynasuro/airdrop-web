# Airdrop Web Simple
A simple airdrop website where only admin can upload airdrops.

## Setup
1. Clone the repo.
2. Install dependencies: `npm install`.
3. Run the server: `npm start`.
4. Open `http://localhost:3000` in your browser.

## Features
- Admin-only upload (password: admin123).
- Airdrop status (Active: green dot, Inactive: red dot).
- View list of airdrops.
